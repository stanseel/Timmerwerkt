# Timmerwerkt Huisstijlgids — GitHub Pages

Dit pakket bevat `index.html`, de volledige huisstijlgids als één zelfstandig HTML-bestand (alle afbeeldingen zijn erin verwerkt — geen losse bestanden nodig).

## Hosten via GitHub Pages

1. Maak op github.com een nieuwe (publieke, of private met GitHub Pro) repository aan, bijvoorbeeld `timmerwerkt-huisstijlgids`.
2. Upload `index.html` naar de root van die repository (via "Add file" → "Upload files").
3. Ga naar **Settings → Pages**.
4. Zet bij "Build and deployment" → "Source" op **Deploy from a branch**.
5. Kies branch **main** en map **/ (root)**, en klik op **Save**.
6. Na ongeveer een minuut staat de gids live op:
   `https://<jouw-gebruikersnaam>.github.io/timmerwerkt-huisstijlgids/`

## Updaten

Voor een nieuwe versie: vervang `index.html` in de repository door een nieuwe versie (via "Add file" → "Upload files", of door het bestaande bestand te bewerken). GitHub Pages werkt automatisch bij, meestal binnen een minuut.
